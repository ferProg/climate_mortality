# Climate Mortality V3 — Pending Improvements

This document lists possible improvements for a future V3 of the Climate Mortality project.

Climate Mortality V2 is considered closed as an exploratory/descriptive portfolio version. The items below are not required for V2, but are preserved as future development ideas.

## Data and normalization

- Add annual population by island.
- Calculate deaths per 100,000 inhabitants.
- Compare islands using relative mortality rates instead of only absolute deaths.
- Review demographic changes between 2009 and 2025.

## Methodology

- Separate more clearly the effects of temperature, calima, seasonality and other factors.
- Document the calima proxy construction in more detail.
- Explore more robust statistical models.
- Evaluate temporal autocorrelation.
- Consider lagged effects if the analysis moves toward a more formal epidemiological design.

## Limitations to address

- Control for COVID-19 effects.
- Control for seasonality.
- Control for age structure if data are available.
- Review irregular coverage in some environmental sources.
- Avoid direct comparisons between islands without population adjustment.

## Dashboard and portfolio

- Create a more polished portfolio dashboard version.
- Add a more visual methodology page.
- Prepare a short case-study explanation for portfolio use.
- Create a PDF or image summary for LinkedIn/GitHub.
- Document more clearly which parts were AI-assisted and which were manually validated.

## Possible future extensions

- Compare mortality in weeks with and without calima.
- Analyze extreme temperature by island.
- Explore PM10/PM2.5 and mortality relationships.
- Create population-adjusted indicators.
- Compare results with existing scientific literature.
